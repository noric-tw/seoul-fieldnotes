# SEOUL / 2026

15-day mobile itinerary and NAVER navigation. Published with the traveler’s explicit consent.

Public site: https://noric-tw.github.io/seoul-fieldnotes/

Travel times are historical queries or planning estimates. Open NAVER for current routes. Saved checklists and notes remain in the visitor browser only. No server or analytics.
